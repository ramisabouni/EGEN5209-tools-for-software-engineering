# Exercise 2 — Linux Files and Permissions

    Work in a copy of `starter/`; do not edit the instructor-managed course copy.

    ## Learning objectives

    - Navigate using absolute and relative paths.
- Create a professional project hierarchy.
- Apply and explain file permissions.

    ## Tasks

    1. Create `workspace/{src,include,tests,docs,data}`.
2. Move the supplied files to appropriate directories.
3. Set scripts to `750`, private data to `640`, and directories to `750`.
4. Record ten useful commands and their purpose in `NOTES.md`.

    ## Deliverables

    - `workspace/`
- `NOTES.md`

    ## Completion check

    Your commands or programs must run without errors, preserve the supplied input files,
    and produce repeatable results. Include a short `NOTES.md` describing assumptions and
    the commands used to test your work.
