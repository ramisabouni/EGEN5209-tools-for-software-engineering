# Exercise 4 — Reliable Bash Automation

    Work in a copy of `starter/`; do not edit the instructor-managed course copy.

    ## Learning objectives

    - Validate arguments.
- Use arrays and functions safely.
- Handle failures and temporary resources.

    ## Tasks

    1. Complete `organize-files.sh` so it sorts regular files by extension.
2. Complete `system-report.sh` so it reports time, host, disk, memory, and required commands.
3. Test missing arguments, spaces in filenames, and empty directories.

    ## Deliverables

    - `organize-files.sh`
- `system-report.sh`
- `NOTES.md`

    ## Completion check

    Your commands or programs must run without errors, preserve the supplied input files,
    and produce repeatable results. Include a short `NOTES.md` describing assumptions and
    the commands used to test your work.
