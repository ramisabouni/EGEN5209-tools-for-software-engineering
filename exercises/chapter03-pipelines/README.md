# Exercise 3 — Pipelines and Archives

    Work in a copy of `starter/`; do not edit the instructor-managed course copy.

    ## Learning objectives

    - Compose pipelines from small commands.
- Search safely with `find`.
- Create and inspect compressed archives.

    ## Tasks

    1. Count log messages by severity.
2. List the five most common HTTP status codes.
3. Find all shell files and validate their syntax with a null-delimited pipeline.
4. Archive your results as `pipeline-results.tar.gz`.

    ## Deliverables

    - `commands.sh`
- `pipeline-results.tar.gz`
- `NOTES.md`

    ## Completion check

    Your commands or programs must run without errors, preserve the supplied input files,
    and produce repeatable results. Include a short `NOTES.md` describing assumptions and
    the commands used to test your work.
