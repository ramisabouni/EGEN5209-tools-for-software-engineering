# Course datasets

These small, synthetic datasets were created for EGEN5209. They contain no real
personal information. Treat files in this directory as read-only inputs; copy a file
to your workspace before an exercise asks you to modify it.

- `csv/`: tabular data for shell, AWK, gnuplot, and Python exercises
- `logs/`: simulated application, web, authentication, and build logs
- `text/`: line-oriented text for regular-expression exercises
- `json/`: configuration and status records for `jq` and Python
- `graphs/`: edge lists suitable for Graphviz processing
